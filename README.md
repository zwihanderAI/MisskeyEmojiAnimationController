# Misskey Emoji ANimation Controller

## 概要
Misskeyを開いているブラウザのウィンドウがアクティブでないとき、カスタム絵文字のアニメーションを停止しGPU負荷を軽減する

## 対象Webブラウザ
- Google Chrome
- その他、Chronium系ブラウザ(MS Edge, Brave, vivaldiなど) ※動作未確認

## インストール方法
1. 本リポジトリをクローンまたはダウンロード
2. ダウンロードした場合、zipで圧縮されているので解凍
3. srcフォルダを任意の場所へ移動<br>
    ※インストール後にsrcフォルダの場所を移動すると拡張機能が正しく動作しない可能性があるため、Cドライブ直下などでパスを固定できることが望ましい
4. Webブラウザにて拡張機能をローカルファイルからインストール<br>
   ※ブラウザにより操作手順が異なるため、各ブラウザの開発者向け資料を参照
5. 既にMisskeyを開いている場合はページリロード

## 使用方法
Misskeyの設定から *環境設定 > アクセシビリティ* にある **アニメーション画像を再生しない** オプションがOFFであること<br>
※オプションをONからOFFへ変更した場合はページリロードすること

Misskeyを開いているウィンドウがアクティブの場合、通常通りカスタム絵文字はアニメーションする。<br>
他のウィンドウを選択するなどによりMisskeyを開いているウィンドウが非アクティブになるとアニメーションが停止する。<br>
アニメーションが停止している場合もタイムライン等はリアルタイムに更新される。<br>
新しいノートが表示された瞬間はカスタム絵文字がアニメーションすることがあるがすぐにアニメーションは停止する。<br>
Misskeyを開いているウィンドウが再度アクティブになると全てのカスタム絵文字はアニメーションする。
